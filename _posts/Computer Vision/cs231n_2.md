x는 이미지 y는 타겟(CIFAR-10의 경우 0~9사이의 정수, 정답 카테고리)
예측함수 : X와 w를 입력으로 받아서 Y 예측
손실함수 Li : f와 정답 Y를 입력으로 받아 얼마나 구리게 예측하는지 정량화 시킴
최종 Loss L : 각 N개 생플들의 Loss 평균

## multi-class SVM loss
여러 클래스를 다루기 위한 이진 SVM의 일반적인 형태
multi-class SVM 손실함수는 조금 재밌게 생김

True인 카테고리를 제외한 나머지 카테고리 (맞지 않는 카테고리 전부 합침)와 올바른 카테고리 스코어를 비교. (올바른 - 올바르지 않은 스코어 ) > 특정 마진(ex: 1) -> Ture 스코어가 False 스코어보다 크다 -> Loss : 0
그렇지 않으면 (올바른 - 올바르지 않은 스코어 ) + 특정 마진(ex: 1)이 된다.
이걸 나머지 클래스에 대해서도 동일하게 순회한다

-> 올바르지 않은 스코어에 margin을 더한 값보다 정답 클래스가 더 스코어 높다 -> Loss:0 그렇지 않으면 해당 값(올바르지않음+1)이 Loss

그래프 모양이 경첩과 비슷하여, 이런 유형의 손실함수 -> hinge loss
loss가 0이다 -> 이 클래스를 잘 분류했다.

s_1:score of cat
y_1:real of cat
s_y_1:score of true class of cat
