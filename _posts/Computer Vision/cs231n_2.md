SVM?

스코어가 있으면, softmax 함수를 가치고 나온 확률값에 log를 추가하고 음수값 부여
만약 이미지가 고양이라면 실제 고양이잉ㄹ 확률은 1이고 나머지 확률은 0
-> softmax에서 나온 확률이 정답 클래스에서 1에 가깝게 계산되게 해야함
-> log를 최대화 시키는 것이 그냥 확률값을 최대화 시키는 것보다 쉬움
-> 얼마나 좋은지가 아니라 얼마나 구린지를 측정하는 것이므로 음수
-> 손실함수 : -log(p(정답 클래스))


리니어 클래스에서 나온 스코어 -> 스코어를 지수화시킴(모두 양수화) -> 합이 1이되도록 정규화 시킴(확률값이 됨) -> 정답스코어에만 -log를 붙여줌 => softmax(또는 multinomail logistic regression)


sl의 민맥스는?
민 : 0 -> Log(1)=0 -> -log(1)=0 : 정답 클래스의 확률이 100%일 때 Loss는 0(완벽한 분류, 이러려먼 정답 스코어는 +무한대 그외는 -무한대가 되어야 함) why? 지수/정규화를 하기 떄문에
맥스 : 양의 무한대 -> log(0) -> -log(0)=양의 무한대 : 정답 클래스의 확률이 0%면 loss는 무한대

디버깅 방법
-log(1/C) = log(C)

why? 정답과 그 외 클래스의 마진이 얼마나 되는지에만 관심있기 때문

반면 소프트맥스(크로스앤트로피)는 확률을 구해서 -log(정답 클래스)에 신경씀
