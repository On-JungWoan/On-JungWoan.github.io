# 1. Abstract

&nbsp;&nbsp;&nbsp;&nbsp;The major challenge of prior vision-language model is prompt engineering. Depending on which prompt is used, there may be an effect on the performance of the model. And, the thing that choosing the correct prompt requires prior knowledge and many hours. CoOp was started inpired by prompt engineering in NLP to solve this problem. And implement the two types of context for image recognition task. Also, CoOp outperform the performance of origin hand-crafted prompt by only 1~2 shot in 11 datasets.

<br>

# 2. Introduction

<img width="100%" src="https://github.com/On-JungWoan/On-jungWoan/assets/84084372/02fdfcb3-8ab1-4d44-ad31-7a6e62d55e89">

&nbsp;&nbsp;&nbsp;&nbsp;The SOTA models for previous CV tasks use discrete labels for supervised laerning. However, these training paradigms have limitations, making zero-shot prediction impossible, as they restrict the model's performance. To address this problem, the Vision-Language Model is proposed as a promising alternative. However, these Vision-Language Model also have limitations, that the model performance is significantly affected by prompt engineering. To address all of these non-trivial tasks, CoOp performs prompt engineering automatically using a learning-based approach.

<br>

<img width="100%" src="https://github.com/On-JungWoan/On-jungWoan/assets/84084372/f158fc6d-f3b9-4b86-9748-cf8692d9d144">

&nbsp;&nbsp;&nbsp;&nbsp;CoOp을 쉽게 표현하자면, CLIP의 prompt 부분을 fine-tuning하는 것이라고 할 수 있습니다. 전체적인 CoOp의 학습 과정은 위 figure에 잘 표현되어 있습니다. CLIP을 그대로 사용하되, 모든 파라미터를 freeze한 채 prompt 부분의 context만 learnable한 vector로 두고, GT와 cross-entropy loss를 걸어 학습을 진행합니다. 여기서 주목해야할 부분은 context 부분인데, CoOp은 다양한 recognition task를 다루기 위해 2가지의 context를 구현하였습니다. 그 중 하나는 unified context로, 모든 class가 동일한 context를 가지며, 나머지 하나는 class-specific context로, class마다 context를 다르게 가져갑니다.

<br>

&nbsp;&nbsp;&nbsp;&nbsp;CoOp은 총 11개의 dataset에 대해 실험을 진행하였으며, 실험 결과 단지 1~2 shot만으로도 hand-crafted prompt의 성능을 높은 마진으로 능가하는 것을 확인할 수 있었다고 합니다. 또한, 더 많은 16 shot에 대해서는 최대 45%까지도 높은 퍼포먼스를 보여주었다고 하며, learning-base approach임에도 불구하고 domain shift에 더 robust한 모습을 확인할 수 있었다고 합니다.

<br>

&nbsp;&nbsp;&nbsp;&nbsp;해당 연구의 contribution은 다음과 같습니다.

- **vision-language model의 downstream application에 대한 시기적절한 연구 제안 & prompt engineering의 중요성 식별**

- **prompt engineering을 자동화하기 위해 continuous prompt learning에 기반한 간단한 방법론 제시 & 다양한 recognition task를 다룰 수 있는 2개의 context 구현**

- **prompt engineering 분야에서, hand-crafted prompt와 linear probe model을 transfer learning performance와 robustness 측면에서 능가한 최초의 learning-base approach**
