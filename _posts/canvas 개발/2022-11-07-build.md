LimeEdu 로그인 페이지의 html, css파일이 오늘 넘어왔다. 내가 받은 파일의 구조는 다음과 같았다.

```
- Components
  - button.html
  - color.html
  - form.html
  - modal.html

- css
  - fonts
    - 폰트파일들
  - import
    - color, font, grid, reset 관련 css 파일들
  - common.css

- html_pages
  - login.html
  - signUp.html
  - signUpModal.html
  - forgotPw.html
  - changePw.html
  - changePwModal.html
  - forgotId.html
  - forgotIdModal.html

- images
  - svg 파일들

- index.html
```

## Components
컴포넌트들이 어떻게 작동하는지 보여주기 위한 예시들인 것 같았다. 실제 소스 적용시에는 사용하지 않았다.

## css
static 파일들이 저장되어 있었다. django의 settings 파일에 static 경로를 지정해 준 뒤, load static하여 사용해주었다.
