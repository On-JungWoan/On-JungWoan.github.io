## URL - View - DB

url 및 뷰 함수를 설계하고 template과 연결시켜주었다. 그리고 서버 DB와 연동하여 기능들이 제대로 동작하도록 해주었으며, 우선 inspectdb로 서버 DB를 쭉 뽑아온 뒤, 필요한 테이블만 추출하여 사용하였다.

<div align="center"><strong>[urls.py]</strong></div>

```python
from django.urls import path
from .views import forgotid, forgotpw, login, signup

urlpatterns = [
    # log in
    path('login/', login.login, name='login'),
    path('login/check', login.login_check, name='login_check'),

    # sign up
    path('signup/', signup.signup, name='signup'),
    path('signup/check', signup.signup_check, name='signup_check'),
    path('signup/modal', signup.signupmodal, name='signupmodal'),

    # forgot pw
    path('forgotpw/', forgotpw.forgotpw, name='forgotpw'),
    path('forgotpw/changepw/', forgotpw.changepw, name='changepw'),
    path('forgotpw/changepw/modal', forgotpw.changepwmodal, name='changepwmodal'),

    # forgot id
    path('forgotid/', forgotid.forgotid, name='forgotid'),
    path('forgotid/modal', forgotid.forgotidmodal, name='forgotidmodal'),    
]
```
