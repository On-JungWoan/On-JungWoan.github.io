## 1. __init__ / __call__의 차이

`__init__`은 인스턴스 초기화 할 때 불러와지고, `__call__`은 인스턴스가 호출됐을 때 실행된다.

### 1-1) `__init__`

```python
class test:
    def __init__(self, data):
        print(data)

T = test('hi')       
```

```
hi
```

### 1-2) `__call__`
```python
class test:
    def __call__(self, data):
        print(data)
        
test('hi')       
```

```
hi
```

## 2. 예외처리 pass
예외처리 시에 아무것도 하고싶지 않으면 `pass`를 입력하면 된다.

```python
try:
    print(가나다)
except:
    pass        
```
