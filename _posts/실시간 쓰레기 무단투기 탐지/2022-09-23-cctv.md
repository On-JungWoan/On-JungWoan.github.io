## 프로젝트 설명
cctv를 통해 쓰레기 무단 투기 행위를 실시간으로 감지하고 경고 음성을 재생하는 프로젝트이며, 현재 시범적으로 6군데에 설치되어 있었다. 
cctv가 설치되어있는 컨트롤 박스에는 gpu와 우분투 기반 시스템이 설치되어 있었고, 터미널에서 미리 작성해둔 스크립트를 실행하여 동작하는 방식인 것 같았다. 
사람의 모션을 디텍션해서 일정 임계치 값을 넘어서면 투기 행위로 감지하는 시스템이라고 하셨다. 

<br>

## 데이터셋 수집
오늘은 현장에 직접 방문해서 프로젝트가 어떤식으로 흘러가는지 확인하고, 그동안 수집된 json 형식 데이터셋을 가져오는 작업을 하였다. 
기존 모델은 아직 불완전하여 해당 데이터셋을 활용하여 파인튜닝 한다고 하셨다. 

<br>

## 최적화 기법
특이한 점은 cuda를 사용하지 않고, TensorRT를 사용하여 gpu 연산속도를 높였다는 것과,
pytorch로 학습된 모델의 내부 python 코드를 모두 c로 컨버팅하여 가볍고 단순하게 만들어 영상 프레임을 40~50프레임까지 높였다는 것이다.
실무에서 실제로 사용하는 최적화 기법을 직접 듣고 두 눈으로 확인할 수 있어서 유익한 시간이었다.
